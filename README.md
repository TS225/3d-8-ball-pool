# 3d-8-ball-pool
The AI slop computing strikes again with new release:
3d 8-ball pool, Python game.
Game is not intended to be a precise simulator game, arcade style playing has been design goal.
1 or 2 player modes, pool 8-ball game only, with 'highlights' last games saving feature. Game saving folder should in game root: pool_replays . Otherwise goes to user profile.
